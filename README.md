# 🔥 Grill Me — Curso INEMA

Curso sobre o skill **grill-me**: como extrair o que está na sua cabeça para o seu sistema de IA.

O modelo é igual pra todos — sua vantagem é o **contexto**. O grill-me te entrevista sem dó, uma pergunta de cada vez, salvando cada resposta em disco (o *capture file*), até que tudo que estava na sua cabeça vire um documento reutilizável.

## Trilhas

1. **🧠 Fundamentos** — por que extrair contexto é o jogo todo.
2. **🎤 As Técnicas** — anatomia de uma entrevista relentless.
3. **🛠️ O Skill** — anatomia do `SKILL.md` do grill-me.
4. **🎯 Avançado** — prompts para aplicar e a dificuldade de responder.

Página única, self-contained (HTML + Tailwind via CDN + camada de aprendizagem INEMA v2: progresso, marcar-lido, dúvida, anotações, "minha jornada", temas).

Abra `index.html` no navegador ou acesse a versão publicada.

Baseado no skill **grill-me** (Matt Pocock) e na variação com checkpointing.
